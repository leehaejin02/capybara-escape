# 제출 문서용 스크린샷

`npm run build:submission`이 이 폴더를 읽어 PDF용 HTML에 이미지를 자동으로 끼워 넣는다.
파일이 없으면 그 자리에 **빨간 자리표시자**가 그려지고 빌드가 종료 코드 1로 실패한다 —
빈 자리를 못 보고 PDF로 굳히는 사고를 막기 위한 것이다.

## 파일 이름

`A.png` ~ `D.png` (또는 `A-title.png`처럼 라벨 뒤에 `-`/`_`/`.`을 붙인 이름도 인식한다).
`.png` `.jpg` `.webp` 를 지원한다.

| 라벨 | 화면 | 반드시 담겨야 하는 것 |
|---|---|---|
| A | 타이틀 | 로고, "클릭 또는 아무 키나 눌러 시작" |
| B | 커스터마이즈 | 미리보기 카피바라에 **옷·모자가 겹쳐진 상태** (기본값 말고 바꿔서 찍을 것) |
| C | 인게임 | **고블린 시야 부채꼴**이 화면에 보이는 장면 + 좌상단 HUD(남은 시간·미션 0/5·하트·대시) |
| D | 미션 미니게임 진행 중 | 미니게임 패널 + 하단 진행 게이지. 배경에 고블린이 보이면 더 좋다 |

## 찍는 법

게임 캔버스는 960×640이다. **캔버스 영역만** 잘라서 저장한다 (브라우저 주소창·페이지 배경 제외).

1. https://leehaejin02.github.io/capybara-escape/ 또는 `npm run dev` 로 연다
2. Windows: `Win + Shift + S` → 사각형 캡처 → 캔버스 테두리 안쪽만 드래그
3. 이 폴더에 `A.png` 같은 이름으로 저장
4. `npm run build:submission` 재실행 → "OK — 비어 있는 자리 없음"이 나오면 끝

> 하네스 12: 영상과 마찬가지로 **실제 플레이 화면만** 쓴다. 합성·편집 금지.
